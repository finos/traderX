# Research and decisions

Use C3 as parent because it combines trading, Kubernetes and development workflow. FDC3 and Radius are optional siblings, not prerequisites. Keep the hardened baseline strong before evaluating residual misuse.

Current technology hypotheses and pinned compatibility evidence are maintained in the [profile research](../012-platform-convergence-c3/security-lab/research.md). Tool candidates are not accepted integrations. Supplier claims require a supported-runtime, install and enforcement contract before comparison.

State 019 avoids existing portal pack 015 and open proposals using 016–018. It is registered as planned until generated deployment acceptance passes. CALM follows as a separate state so learners can compare explicit control implementation against model-derived artifacts without attributing unimplemented enforcement to the architecture model.
